# Day 1 — Pre-Training Survey (Menti) — Suggested Questions
For the 09:00–09:15 "Pre-Training Survey & Expectations Capture" slot. Delivered live via Menti
(placeholder slide only in `index.html`) — build these as actual Menti questions before the wave.

Purpose: establish a baseline to compare against the Day 3 post-training survey (per SOW §10
Acceptance Criteria — "confidence improvement, usefulness of labs, readiness to apply Claude Code").
Keep to ~8 questions max so it fits inside 15 minutes including instructions.

1. **What best describes your primary stack?** *(Multiple choice)*
   - Java
   - .NET
   - Both
   - Other

2. **How would you describe your current use of AI coding tools today?** *(Multiple choice)*
   - Rarely/never use one
   - Occasional autocomplete (e.g., inline suggestions)
   - Regular use as an assistant (ask → get one answer)
   - Already delegating multi-step tasks to an agent

3. **Which AI coding tools have you used before?** *(Multi-select)*
   - GitHub Copilot
   - Claude / Claude Code
   - ChatGPT / other chat assistant
   - None
   - Other (please specify)

4. **On a scale of 1–5, how confident are you using Claude Code today?** *(Rating scale, 1 = not at all, 5 = very confident)*

5. **On a scale of 1–5, how comfortable are you delegating a multi-step task to an AI agent without checking every intermediate step?** *(Rating scale — baselines the Stage 1→3 mindset progression taught today)*

6. **What's the biggest pain point in your current development workflow?** *(Open text / word cloud)*

7. **What's one legacy system or workflow you'd love to modernize with AI?** *(Open text — primes Day 3 relevance)*

8. **What outcome would make these three days worth your time?** *(Open text)*
