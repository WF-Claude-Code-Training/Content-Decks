Day 1 · Foundations & the Agentic Mindset

09:00 – 17:00
Arc: Day 1 moves from what the models are to getting real work done in Claude Code. The morning builds a lean shared foundation around a mindset shift. Your developers have lived in GitHub Copilot, which is designed for autocomplete and single-file completion. Agentic coding serves a different job. It supports multi-file refactors, multi-repo work, and delegating an outcome for review. That is the shift this program builds on. The morning then defines what Claude Code is, the Read → Decide → Act → Observe loop, where the value shows up, and how to use it responsibly in wealth management. It puts every participant in Claude Code before lunch. In Lab 1, they use a starter Skill to implement and verify a management-fee fix. The afternoon builds on that first contact. Participants learn the interface and CLAUDE.md. In Lab 2, they use an existing Skill to correct advisory-fee calculations. They then develop and invoke a fee-specific Skill that can be reused across different time frames. They next use plan mode to give Claude a verifiable target. The day stays practical rather than going deep into model internals. It is designed as a 50/50 lecture-to-hands-on experience.
Morning · Foundations, First Contact & the Agentic Mindset (09:00 – 12:30)
By the end of the morning you can
  • Verify your own Claude Code environment in VS Code and get unblocked before content starts.
  • Describe the Read → Decide → Act → Observe loop and name a task in your day where an agent adds value, and one where it doesn't.
  • State what code and data you may send under Wells Fargo's managed deployment, and how NPI/PCI and retention are handled.
  • Rewrite a single-turn prompt into an agentic task frame with an explicit outcome and a verification step, then use a starter Skill to implement a management-fee fix.
  • Verify an application change with test evidence, not just a claim that it works.

Day 2 · Extending an Enterprise Codebase, the Right Way

09:00 – 17:00
Arc: Day 2 keeps the same Agentic Mindset focus and grows it. Learners will discover subagent architectures and use them to understand an existing system, map its dependencies, and find the right change point. A short demo showing that same workflow connect to a live external system via MCP, and the afternoon implements real enterprise features (logging, error handling/retries) as realistic "change in an existing codebase" work. Every lab foregrounds a VS Code best-practice cluster and, where a workflow is worth keeping, packages it as a scoped, shareable Skill or subagent. Each feature maps to an existing backlog ticket, so we extend rather than build.
Morning · Understand the System (09:00 – 12:30)
By the end of the morning you can
  • Read and navigate an unfamiliar legacy or distributed system using Glob, Grep, and Citations to understand its structure and data flow.
  • Use an agent to map dependencies across services, extract the critical path, and identify the right change point for a new feature.
  • Document the system's rules and interfaces so you can safely extend it without breaking the existing contract.

Day 3 · Modernization & Greenfield Delivery

09:00 – 17:00
Arc: Day 3 applies the full toolkit to one real Wells Fargo greenfield build, end to end: stand up a reusable Skills and subagent framework and build a greenfield service, then measure the result and lock in a sustainment plan.
Section 1 · Project Setup & Delivery Sprints (09:00 – 17:00)
By the end of this section you can
  • Stand up a project's reusable framework: CLAUDE.md, Skills, and .claude/agents/*.md subagent.
  • Operate in sprint-based pods or individually, iterate on a working use case, and close with a crisp sustainment plan tied to KPIs and ownership.
